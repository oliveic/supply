# Supply Management System

Sistema de gerenciamento de suprimentos e cálculo de necessidades.

## Requisitos

- PHP 7.4 ou superior
- MySQL/MariaDB
- XAMPP (ou servidor web similar)

## Configuração

1. Clone o repositório
2. Configure o arquivo `connection.php` com suas credenciais de banco de dados
3. Importe o banco de dados (se houver arquivo SQL)
4. Acesse o projeto através do servidor web

## Estrutura

- `index.php` - Página principal
- `calculo_necess.php` - Cálculo de necessidades
- `connection.php` - Configuração de conexão com banco de dados
- `bom/` - Arquivos relacionados à lista de materiais (BOM)
